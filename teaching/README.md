# Teaching pages

- `/teaching/`: teaching index.
- `/teaching/linear-algebra/`: shared course outline and semester index.
- `/teaching/linear-algebra/2026F/`: one page for this semester’s schedule and materials.
- `/teaching/linear-algebra/cofficients/` and `/teaching/linear-algebra/linvis/`: independent interactive systems, reused across semesters. Legacy `/demos/` URLs redirect to these canonical paths.

To add a semester, create its `index.html`, then link it from the course semester list and the homepage Teaching section. Keep reusable materials under the course folder and link to them from each schedule.

2026F outline and schedule were curated from the local 2026F-LA curriculum (semester architecture §7.2 and N1/N2 lecture plans). Internal planning documents and student information are not published. School-calendar week numbers were confirmed by the instructor; the midterm date remains provisional. Each lecture lists a theme question, knowledge points, textbook coverage, resource links, and a task disclosure. N1/N2 assignments use the current lesson plans; five chapter-level AI practices are labeled as planned. Unassigned tasks and unpublished reference lesson plans are not invented.

Cofficients is the self-contained offline build from `TEACHING/Cofficients-offline.html`. LinVis is built from `guoquan/LinVis` with a relative asset base. Update the system directories when new versions are ready.
