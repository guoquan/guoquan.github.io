# Teaching pages

- `/teaching/`: teaching index.
- `/teaching/linear-algebra/`: shared course outline and semester index.
- `/teaching/linear-algebra/2026F/`: one page for this semester’s schedule and materials.
- `/teaching/linear-algebra/demos/`: shared demonstrations; do not duplicate under semester folders.

To add a semester, create its `index.html`, then link it from the course semester list and the homepage Teaching section. Keep shared materials under the course folder and link to them from each schedule.

2026F outline and schedule were curated from the local 2026F-LA curriculum (semester architecture §7.2 and N1/N2 lecture plans). Internal planning documents and student information are not published. School-calendar week numbers and the midterm date require confirmation.

Cofficients is the self-contained offline build from `TEACHING/Cofficients-offline.html`. LinVis is built from `guoquan/LinVis` with a relative asset base. Update the shared demo directories when new versions are ready.
